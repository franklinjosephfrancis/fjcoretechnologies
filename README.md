# FJ Core Technologies — Netlify Ready

This is a static website prepared for Netlify.

## Deploy
1. Unzip this folder.
2. In Netlify, create a new site and choose manual/deploy upload.
3. Upload the contents of this folder (the files such as `index.html` must be at the deployment root).

## Contact form
The contact form uses Netlify Forms (`data-netlify="true"`). No PHP, database, or separate backend is required. After deployment, Netlify detects the form and stores submissions under the site's Forms area. The form redirects to `thank-you.html` after successful submission.

## Important
If you deploy by uploading the folder, upload the folder contents so `index.html` is at the site root.
